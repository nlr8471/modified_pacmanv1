# Pacman Game

A browser-based Pacman game developed using HTML, CSS, and JavaScript. The project recreates the core gameplay experience of Pacman, allowing players to control the character, navigate through the game environment, and interact with the game elements through a simple web-based interface.

## 🎮 Features

* Interactive Pacman gameplay
* Keyboard-based player controls
* Structured game interface with HTML
* CSS-based styling and game layout
* JavaScript-based game logic and player interactions
* Separate game page and landing page
* Browser-based gameplay without requiring additional software

## 🛠️ Technologies Used

* **HTML5** – Used to structure the game pages and interface.
* **CSS3** – Used for styling the game interface, layout, and visual elements.
* **JavaScript** – Used to implement the game logic, player controls, and interactions.

## 📂 Project Structure

```text
Pacman/
│
├── index.html      # Main/landing page
├── game.html       # Game interface
├── styles.css      # Styling and layout
└── game.js         # Game logic and interactions
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/JK79023/Pacman.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

4. Navigate to the game and start playing.
